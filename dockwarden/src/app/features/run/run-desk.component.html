Secret run

Start a command with vault fields in its environment. This is the personal-vault version of op run. Secrets Manager is not required.

{{ listening() ? 'Unlocked' : 'Locked' }}

Put references in an env file or on the command line. DockWarden resolves them only while this vault is unlocked, and only the fields you name.

API_TOKEN=dw://your-item-id/password
DATABASE_URL=dw://your-item-id/uri

Fields: password, username, notes, uri, totp (the current code, not the seed), or a custom field name. The item can be its name when that name is unique, or its id.

What this does not do

Any program on this computer that can read the local token file can ask for those fields while the vault is unlocked. Locking DockWarden deletes the token. The command you run receives the secrets in its own environment, the same way a shell export would.
